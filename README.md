# Hey, I'm Kashi 👋

I'm a Computer Science undergrad at Anurag University in Hyderabad (graduating 2027). I like backend engineering and AI/ML, and I care most about software that keeps working once real users and real traffic show up.

Last year I was Tech Lead at Viswam AI and went through an AI programme run with Meta and IIIT Hyderabad. Most of my time there went into backend work: cutting API latency and getting ML pipelines out of notebooks and into production.

## 🔭 What I'm into

- Backend engineering and system design
- AI/ML, especially getting models to behave in production
- Multilingual language technologies
- Open-source communities and learning in public

## 🛠️ What I'm working on

- **[CollabOS](https://github.com/codegeekpy/CollabOS)**: a decentralized project management app (MERN + blockchain) for IoT projects, built to create trust between overseas clients and developers. Still in progress.
- **[Genai Forge](https://github.com/codegeekpy/Genai_forge_2026_Devs)**: an AI career readiness platform I built in 24 hours at a hackathon. It does skill roadmaps, resume analysis, job-readiness checks and ATS-friendly resume design, with sub-second responses. React, FastAPI, Gemini/Groq APIs.
- **StudyGen.ai**: FastAPI + LLM pipelines.
- **BERT-based medical triage classifier**.
- **[Spring Boot project](https://github.com/codegeekpy/Technical-Training-2026-)** from my technical training.
